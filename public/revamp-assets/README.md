# Revamp assets

Theme-specific art for the **2026 home revamp** and future updates. Paths are served from the site root (e.g. `/revamp-assets/...`).

Layout mirrors `public/assets/` so files stay easy to find:

| Path | Purpose |
|------|---------|
| `branding/` | Wordmarks, marks, partner strips (add as needed) |
| `images/ambient/` | Soft washes, vignettes, non-photo atmosphere |
| `images/backgrounds/` | Full-bleed plates, section backdrops |
| `images/hero/` | Home hero focal art, scroll-expand keys |

## Current files

- `images/hero/home-hero-primary-2026-05.png` — **full-viewport** background for main home (`/`) hero (`heroContent.homeHeroFullBleedBackgroundSrc`). **No** color wash overlay on the image (copy relies on photo + foreground styles).

When adding assets, prefer **lowercase, hyphenated filenames** (no spaces) for stable URLs.
