# Fonts similar to commercial “Runtime” (display serif)

If you ever license the **Runtime** display serif from a foundry, you can host WOFF2 under `public/fonts/` and add `@font-face` again. This repo now uses **Fraunces** + **Plus Jakarta Sans** only (no local Runtime file).

## Previously local file (removed)

The project used to ship **`public/fonts/Runtime-Regular.otf`** (single Regular master). Heavier CSS weights were mostly synthesized; **Fraunces** on Google Fonts gives real **400–900** files instead.

## Options (Google Fonts)

| Font | Vibe | Google Fonts |
|------|------|----------------|
| **Fraunces** | **Default in this repo** — multi-weight display serif | [Fraunces](https://fonts.google.com/specimen/Fraunces) |
| **Cormorant Garamond** | High-contrast Didone, magazine / spa luxury | [Cormorant Garamond](https://fonts.google.com/specimen/Cormorant+Garamond) |
| **DM Serif Display** | Clean classical display (only regular; bold is faux) | [DM Serif Display](https://fonts.google.com/specimen/DM+Serif+Display) |
| **Instrument Serif** | Sharp 2020s editorial (limited weights) | [Instrument Serif](https://fonts.google.com/specimen/Instrument+Serif) |
| **Libre Bodoni** | Strong Bodoni poster feel | [Libre Bodoni](https://fonts.google.com/specimen/Libre+Bodoni) |
| **Playfair Display** | Widely used high-contrast headline serif | [Playfair Display](https://fonts.google.com/specimen/Playfair+Display) |

## If your Runtime file is actually a **sans** (different product)

Try **Syne**, **Outfit**, **Manrope**, or **Space Grotesk** on Google Fonts—geometric / neo-grotesk display sans with full weight ranges.
