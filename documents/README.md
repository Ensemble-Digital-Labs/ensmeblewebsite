# Documents – session logs

This folder holds **session logs** from coding work, organized by date.

## Structure

```
documents/
  2025-03-10/
    session-2025-03-10.md
    session-2025-03-10-cursor-rules.md   (optional: multiple logs per day)
  2025-03-11/
    session-2025-03-11.md
  ...
```

- One folder per day: `YYYY-MM-DD`
- One or more markdown files per day with a summary of what was done in that session

Logs are created by the Cursor AI when you end a session or ask to save what was done.
